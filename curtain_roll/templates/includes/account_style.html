{#- Styling for every /account page, and for the cart. Written against the redesign's own CSS custom properties rather than fixed colours. The shell carries that stylesheet, so these pages pick up the palette, radii and shadows the rest of the site uses, and follow it if the design is retuned. The fallbacks after each var() are only for the case where the shell is ever cut from a page that does not define them. Deliberately NOT reusing the theme's own .container or .breadcrumb classes. .container is a flex row here, which turned the page into columns and dropped its padding; .breadcrumb is set to display:none, so the trail rendered into the DOM and was never seen. Borrowing classes from a design that has never seen this page is a losing game. Everything is scoped under .cr-acc so none of it reaches the product pages. -#}
